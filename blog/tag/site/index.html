An analytics dashboard joins the squadron PENDING

The mission desk wants numbers, so numbers it gets — a proper analytics dashboard, plus the plumbing that feeds it:

  1. New dashboard at /analytics, styled to the squadron: SORTIE RECORD (missions flown, flight hours, ejections), COMBAT RECORD (MiG kills, AIM-9 and AIM-120 fired, hits by type, cannon rounds, gun hits) and PILOT CHOICES — Hornet versus Falcon picks, and how often each free-flight start point gets the nod, bars and all.
  2. Every metric is counted as you play. Missions, flight time, MiG kills, plane and start-point selections, ejections, missiles by type, cannon rounds, missile hits by type and gun hits are all tracked live and kept between sessions. One honest caveat: the dashboard reads the counters in your browser — clear your storage and your record starts over.
  3. Every metric also fires as a Google Analytics event — mission_flown, flight_time, mig_kill, plane_select, start_point_select, ejection, missile_fired, cannon_rounds_fired, missile_hit and gun_hits — so the fleet-wide picture across all players builds in the GA4 property. High-frequency streams (flight seconds, cannon rounds, gun hits) batch up and report once a minute and at the end of every sortie; the rest report the moment they happen.
  4. ANALYTICS DASHBOARD is a main-menu item (key A, opens in a new tab) — and DEMO has left the menu; the attract loop still runs behind the menu as always, it just no longer takes up a row.

Two menu-router bugs surfaced while wiring all this up, and both are fixed:

  1. One keypress was being spent twice. Hitting 2 for FREE FLIGHT used to open the start-point map and — in the very same instant — let that same 2 fall through to the map and pick Oakland for you. The menu now swallows any key it consumes.
  2. F1–F7 work in MISSIONS again. The rows always said F1, F2, F3… but the keyboard router wasn’t listening for F-keys — mouse or nothing. Now the keys do what the badges promise.

The Exchange: a print-on-demand squadron store, built API-first 7fb9f03

Squadron stores are coming: hornetbay.com/store — The Exchange — is live today in preview mode with the planned catalog and target prices. The launch lineup: a navy dad cap with the embroidered insignia, all seven embroidered iron-on patches (Carrier Ops Certified plus the six reward badges — collect them all), an 11oz insignia mug, a sticker sheet with every badge, and a navy wordmark tee. Everything is printed on demand when ordered and shipped worldwide — nothing sits in a hangar; checkout, payment and sales taxes run through Fourthwall as merchant of record, so there’s no Shopify and no stockroom.

The whole store is built API-first. A new embroidery-safe variant of the insignia (five thread colors, flat grays) leads a production artwork pack; a product spec defines all eleven SKUs; and a setup script drives Fourthwall’s Platform API — artwork upload, product-template matching, mockup rendering, pricing as base cost plus margin — so the catalog is created by code, not an afternoon of clicking. The storefront page itself is custom headless: it will pull the live catalog from the Storefront API and hand buyers to hosted checkout, all without leaving hornetbay.com. The only missing piece is the shop account itself — once it’s connected, The Exchange flips from preview to open for business. Digital badges and wallpapers, as always, stay free at the quartermaster.
