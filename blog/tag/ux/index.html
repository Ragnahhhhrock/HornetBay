The tower would like a word: the sortie poll 0b53c94

Every sortie now ends with one quick question. Mission complete or mission failed, the debrief card carries a poll — and if you go into the bay, the tower asks on the way out:

  1. The poll rides the debrief. RATE THIS SORTIE: one to five amber stars, an optional note for the tower, SUBMIT. No extra screens — it’s part of the card you’re already reading, once per sortie.
  2. Crashes get their own card. The 1988 original dumps you straight back at the menu — no paperwork, no debrief. That stays. But once the wreck or the chute ride has settled, an AIRCRAFT DOWN card asks the same quick question, with SKIP right there if you’d rather not.
  3. It speaks up exactly once. The crash gate used to re-fire every frame — fine when it just quit to the menu, fatal for a form. The gate now closes as the card opens, so your stars and your note are never stomped mid-sentence.
  4. Wiring is a two-minute job, deliberately. Ratings post to a form-service endpoint (Formspree or Web3Forms free tier): paste one URL into FEEDBACK_ENDPOINT and every submission lands in that dashboard and emails maverick@hornetbay.com. Until then the poll stays hidden, and ?fbtest flies it in test mode with the payload logged to the console — no backend, no database, no monthly bill for a site this size.
  5. Each report carries the sortie with it — stars, note, mission id, result, score, kills, timestamp and browser — enough to spot a rough mission or a rough build without a server of our own.

Every rung of the ladder: the great consistency pass 697ca69

A full audit of every menu, sub-menu and page on the site — hunting for dead ends, clipped text, hidden keys and wandering navigation. Nine issues found, nine issues fixed:

In the cockpit

  1. ESC was dead on the free-flight map. Pick FREE FLIGHT, change your mind — and there was no way back short of reloading. ESC now steps back to the menu.
  2. ESC was dead on plane select. Same trap, one screen later. ESC now steps back one level: to the start-point map for free flight, to the menu for a mission (where BACK TO MISSION waits).
  3. The plane-select line was clipped. Five jets and the toggles on one line ran clean off both edges of the screen — you literally could not see the F-16 or the Tomcat. The bar is now a three-row panel: two rows of aircraft, then TIME / WX / ESC, every option visible.
  4. Every selection bar now says so: ESC — BACK rides the map select, plane select and briefing bars.
  5. Main-menu keys renumbered and shown. The rows were bound to 1, 2, 6, 8, 9 — with the badges hidden, so three dead keys and no way to discover the live ones. Now 1–5, sequential, and every row wears its key like the sub-menus always did.
  6. Mission keys every keyboard has. The board was bound F1–F16 — and F13–F16 don't exist on most keyboards, leaving four missions mouse-only. The board now runs 1–9, 0, A–F with badges shown; F1–F12 stay bound as silent aliases for anyone who learned them.
  7. FLIGHT MANUAL wears its H.

On the site

  1. One site ring on every page. Cross-links used to wander the headers — STORE · ASSETS here, STORE · ASSETS · PRINT there, nothing at all on the blog. Now all 209 pages carry the same row under the nav buttons: SQUADRON STORE · WALLPAPERS & ASSETS · 3D PRINT BAY · ANALYTICS, with the current section painted amber. It lives in the shared template, so every future page is born with it.
  2. Sub-headings in posts are styled — amber, letter-spaced, on-guide — instead of falling back to browser defaults.

What survived the audit unchanged: the masthead stack, the two-button nav rail, the blurb sizes, the search rail, the tag cloud and the mobile stacking — all already in formation. One look, one feel, every page.

Sideways by default: no overlay, no waiting — just the game e77e000

MOBILEUX

Product call from the boss: "Instead of waiting for the phone to rotate, just serve the game and fix for landscape. The user will figure it out." Correct. So the ROTATE YOUR DEVICE overlay is gone. A phone held upright now gets the game immediately — the whole thing laid out for landscape and spun 90 degrees, menu included (above). It looks sideways on an upright phone; the pilot turns the phone; done. The gyro, once permitted (one tap, asked on the first touch), simply flips which way the game spins if they turned the "wrong" way, and a viewport that genuinely rotates to landscape always wins natively. Rotation lock is now fully irrelevant either way.

Serving the menu inside a portrait viewport surfaced two fun bugs. One: engaging the spin at startup called the resize path before the HUD module existed — a TDZ crash that only fired in portrait, leaving the menu unbuilt (thank you, errbox). The re-layout is now deferred a frame. Two: the compact phone menu is gated on @media (max-height: 480px) — and a portrait viewport is 844 tall, so the full-size desktop menu rendered into a 390-tall game screen and the flex column crushed the button list to 33 pixels. The compact rules are now replicated under sideways mode, along with swapped vw/vh units throughout, and the suite checks the menu is genuinely tappable through the rotation: 51/51.

First solo: a quick-start card, a DEMO that demos, and a trackpad stick 9a4a5df

CONTROLSUX

First feedback from a new pilot on a MacBook: "can't get off the ground." Fair — the sim never told you how. Three fixes. Every launch now opens a quick-start card with the handful of keys that get you airborne (W to firewall the throttles, B brakes off, pull back at 150 knots, G gear up, ? for the full manual) — it fades by itself, closes on a click, and has a don't-show-again tick for veterans. The DEMO menu item actually demos now: it hides the menu and plays the attract loop full-screen until any key brings you back (previously it did exactly nothing, since the demo jet was already flying behind the menu). And the mouse stick grows up: press Y, then click the screen to capture the cursor — pointer lock turns relative movement into stick deflection, which is how the Amiga original flew and, crucially, the only way a trackpad can.
